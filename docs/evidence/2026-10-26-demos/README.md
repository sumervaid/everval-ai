## Executed checks

- Recorded 98 UI keyframes through the actual Textual or browser interfaces.
- Built eleven GIFs containing 118 frames, including the overview.
- Decoded every GIF and compared every rendered frame with the encoded source pixels.
- Verified dimensions, frame counts, loop settings, total duration, SHA-256 hashes and PNG decoding.
- Visually inspected capture contact sheets and representative full-size frames.
- Browser captures reported zero JavaScript errors; owned servers and capture applications were closed.
- Autopilot was left paused. No model API calls were made.
- Capture/encoder lint, formatting, local documentation links and whitespace checks passed.

The terminal audit view replaces the local OS account label with operator; no evidence or outcome is altered. Raw workspaces, credentials, SVG intermediates and logs remain outside Git. The application revision is retained in the [media manifest](../../assets/demos/manifest.json).

## Interpretation

These are edited interface walkthroughs with readable pauses. They are not latency measurements or model-quality studies. Repository onboarding remains visibly pending at isolated validation. Checkpoint observations are synthetic. Blind reviews use scripted identities rather than independent human participants. The npm 0.3.1 package predates several recorded source features.

Application behavior was not changed for these demos. The existing application test suite was not rerun for documentation and media changes; the capture recipes were executed against the actual product.
